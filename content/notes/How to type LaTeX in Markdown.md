To write inline LaTeX formulae, use a single `$`before and after the equation and use a double `$` to display equations. Everything else is as per LaTeX. This is a great [reference](https://ashki23.github.io/markdown-latex.html#latex).

e.g. $equation$.
$e = \sum_{t=1}^{\inf} \frac{1}{t!}$ .
